# Repository routing

- This directory contains the RX firmware and belongs only to `https://github.com/EPIIIC/VNS_RX.git`.
- Never push this directory to the legacy `VNS_nRF` repository.
- Future RX or TX/RX-format firmware changes must keep RX code in `VNS_RX` and matching TX code in `VNS_TX`.
- Do not commit generated `build` output or local `verification` snapshots.
